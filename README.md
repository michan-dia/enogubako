# 絵具箱（ブラウザ版）

アルコールマーカーの書き味を再現したアナログ風ペイントアプリです。

このフォルダの中身を GitHub Pages で公開すると、ブラウザから使えます。
iPad では Safari で開いて「共有」→「ホーム画面に追加」すると、アプリのように全画面で使え、一度開いた後はオフラインでも動きます。

- 作品は、使っている端末のブラウザの中に自動保存されます（サーバーには送られません）。
- 大事な作品は「書き出し」→「作品ファイル（.zip）」で保存してください。
- 文字のフォントは Google Fonts から読み込みます（一度読み込んだ後はオフラインでも使えます）。
